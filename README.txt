VOLTACHORD PROMOTIONAL WEBSITE
=============================

Contents:
- index.html : website structure and content
- style.css  : layout, responsive styling and visual design
- script.js  : mobile navigation and footer year

RUN:
1. Extract this ZIP.
2. Open index.html in any modern web browser.

DEPLOY:
This static website can be hosted on GitHub Pages, Netlify, or similar static hosting.

NOTES:
- This is a promotional landing page; the sample device interface is illustrative and does not connect to the actual VoltaChord hardware/app.
- Font styling uses Google Fonts and requires an internet connection; fallbacks are included.
